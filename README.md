# 櫻卡 · Sakura Card 2.0

原生 SwiftUI iOS 26 支付回饋比較 App，支援日本語／繁體中文。

- 8 款主題與深淺色
- 12 張卡片、64 間商戶識別資料
- 商戶與卡片搜尋、繁中／英文別名、分類篩選
- 收藏預設置頂、本機 JSON 儲存與備份
- Apple MapKit 附近店鋪、地址、距離、步行導航、分店收藏
- 官方來源與條件說明，Prime／PayPay 資格控制與優惠活動管理
- 使用者指定的 App 圖示

開啟 PayCompass.xcodeproj，Xcode 26+。GitHub Actions 可雲端產生未簽名 iPhone IPA；安裝前需自行簽名。保持原 Bundle ID 以支援覆蓋升級。

新版說明及資料來源：UPDATE_2.0_中文.md。v1 說明檔僅供歷史參考，最新功能與實際驗證結果以本 README、更新說明及 Actions 執行記錄為準。
