# 更新记录

## 1.2.0（构建 3）

- 新增独立「发现」Tab，内置 Mayhempedia 修订 1dd16f15 的 173 位英雄、233 条构筑攻略。
- 新增 666 条 ARAMMayhem 公开组合标签，其中 355 条为多强化组合；公开数据未提供的机制说明、胜率和完整玩法长文均不补造。
- 每条显示来源、许可、适用版本字段、更新时间含义、快照获取时间、上游引用与修改说明；单条未声明的版本和更新时间明确标记，不以下载时间替代。
- 新增 BuildGuide、三来源 Adapter 及独立 HexPickGuides 模块；AstrBot/Apexlol 内容不接入生产。
- 来源冲突保留各自条目，不合并核心、备选、避坑或装备顺序。
- 接入 200 件 ARAMMayhem 装备目录，与 CommunityDragon 图标及说明交叉核对。构筑使用的 136 个装备 ID 及补充目录中的 200 个 ID 均有图标路径；失败 ID 清单为空。
- 将原强化图标缓存扩展为强化／装备共用管线：NSCache、磁盘缓存、版本键、7 天有效期、重试及全局 4 并发、后续 8 项预取。
- 强化按来源命名空间映射，补全稳定标识和名称别名；Mayhempedia 的 910103（绝活玩家）、910005（虚空献祭，历史项）无法确认 CommunityDragon 路径，保留占位并列入报告。
- 陷阱强化添加警告边框与角标；来源未提供逐项避坑原因时明确说明，不编造失效版本。
- 关于页分列 Mayhempedia（MIT）、ARAMMayhem（CC BY 4.0）、aramhex-data（CC BY-NC 4.0）；内置完整 Mayhempedia MIT 版权与免责文本。
- 原始统计 JSON、解析器、更新器、RecommendationEngine 与 AppStore 保持不变。
